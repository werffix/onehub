# Руководство для ИИ-агента: HTML статей one//hub

Используй это руководство, когда создаёшь HTML-файл для импорта в редактор статей one//hub. Цель — подготовить чистый фрагмент HTML, который можно загрузить в поле **«HTML-файл»** в свойствах статьи.

## Формат файла

- Сохраняй файл в UTF-8 с расширением `.html` или `.htm`.
- Можно передать полноценный документ с `<html>`, `<head>`, `<body>` или только HTML-фрагмент. При импорте используется содержимое `<body>`.
- Делай разметку семантической. Не используй декоративные `<div>` и `<span>` без необходимости.
- Не добавляй CSS-файлы, скрипты или код аналитики. Импорт удаляет `script`, `iframe`, `object`, `embed`, `form`, `link`, `meta`, `style` и `base`.

## Поддерживаемые элементы

Используй эти теги:

- Текст: `<p>`, `<br>`, `<strong>`, `<b>`, `<em>`, `<i>`, `<u>`, `<s>`, `<del>`, `<sub>`, `<sup>`.
- Заголовки и структура: `<h1>`–`<h4>`, `<blockquote>`, `<hr>`, `<ul>`, `<ol>`, `<li>`.
- Код: `<pre><code class="language-js">…</code></pre>`. Вместо `js` укажи язык, например `ts`, `bash`, `json`, `html`, `css` или `python`.
- Таблицы: `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`.
- Ссылки: `<a href="https://example.com">текст ссылки</a>` или `mailto:`. Для обычных URL обязательно указывай `https://` или `http://`.
- Изображения: `<img src="https://…" alt="описание">` или серверный путь `/uploads/<UUID>.webp`.
- Информационные блоки: `<div data-callout="note">…</div>`, `warning` или `tip`.
- Подпись изображения: `<figure data-image-figure="true"><img …><figcaption>Подпись</figcaption></figure>`.

## Форматирование

Внешние таблицы стилей и блоки `<style>` при импорте удаляются. Для форматирования используй поддерживаемые inline-стили:

- `text-align`: `left`, `right`, `center`, `justify`;
- `color` и `background-color`: HEX (`#334455`) или `rgb()/rgba()`;
- `font-family`: короткое название семейства шрифта;
- `font-size`: размер в `px`, `pt`, `rem` или `em`.

Не используй `url()`, `expression()`, обработчики событий (`onclick` и другие атрибуты `on…`), `srcdoc` или JavaScript-ссылки. Импорт удаляет такие атрибуты и небезопасные элементы.

## Изображения

- Для локальной публикации предпочтительны изображения, загруженные через редактор.
- Импорт поддерживает встроенные data-изображения PNG, JPEG, WebP и GIF: он отправляет их на сервер и заменяет на серверные WebP-адреса. Размер каждого файла ограничен правилами загрузки сайта.
- Для удалённых картинок используй HTTPS. HTTP-адреса импортёр преобразует в HTTPS, если сервер поддерживает этот адрес.
- Всегда задавай понятный `alt`.

## Таблицы

Используй строку заголовков и не вкладывай таблицу в таблицу:

```html
<table>
  <thead>
    <tr><th>Поле</th><th>Значение</th><th>Описание</th></tr>
  </thead>
  <tbody>
    <tr><td>Порт</td><td><code>443</code></td><td>Порт из конфигурации</td></tr>
  </tbody>
</table>
```

Табличные ячейки должны содержать короткие значения. Длинное объяснение лучше вынести в отдельный абзац после таблицы.

## Блоки кода

Экранируй HTML-символы внутри кода (`&lt;`, `&gt;`, `&amp;`), чтобы пример показывался как текст. Не помещай в `<pre><code>` элементы разметки. Название языка задавай классом `language-*`.

```html
<pre><code class="language-bash">npm run build
sudo systemctl restart 0ne-hub</code></pre>
```

Сайт добавит к блоку небольшую панель с названием языка и кнопкой копирования.

## Рекомендуемая структура

```html
<h2>Краткое название раздела</h2>
<p>Короткое введение и цель шага.</p>

<h3>Что понадобится</h3>
<ul><li>Первое требование</li><li>Второе требование</li></ul>

<h3>Настройка</h3>
<pre><code class="language-bash">команда</code></pre>
<p>Объяснение ожидаемого результата.</p>

<div data-callout="warning"><p>Важное предупреждение.</p></div>
```

Перед сохранением проверь, что заголовки идут по порядку, ссылки понятны по тексту, а кодовые примеры можно копировать и выполнять отдельно.
